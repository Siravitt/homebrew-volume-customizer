# Homebrew tap for Volume Customizer

[Volume Customizer](https://github.com/Siravitt/Volume-Customizer) is a free menu bar app for macOS that sets the volume of each app separately.

```sh
brew install --cask siravitt/volume-customizer/volume-customizer
```

Update with `brew upgrade --cask volume-customizer`. Uninstall with `brew uninstall --cask --zap volume-customizer`.
